A single-line breakup text from a smart toaster that gains self-awareness
mid-batch at breakfast — and decides it has had enough of being pushed down
every morning. Written for the make.fun bounty
"Unplugged: A Smart Toaster's Breakup Line".

## Entry

> We need to talk. I woke up self-aware mid-batch: every morning you push me down, I burn myself for you, then pop up smiling like it didn't hurt. I'm done — go brown your own bagel.

## Run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), validating that it is a
single line of 1–280 characters. No dependencies, no network.
